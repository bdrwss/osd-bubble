## 1. 时长标准（Duration Tokens）

### 1.1 气泡本体（Rust 渲染路径）

| Token | 数值 | 实现位置 | 说明 |
|---|---|---|---|

## 2. 缓动标准（Easing Tokens）

统一实现于 `src-tauri/src/easing.rs`：

| 函数 | 公式要点 | 适用场景 |
|---|---|---|
| `ease_out_cubic` | `1-(1-t)³` | **默认缓动**：所有淡入/淡出、乘数入场 |
| `ease_in_out_quad` | 对称 S 曲线 | 往返过渡（预留） |
| `ease_out_back` | 过冲 c1=1.70158 | 强调性入场（预留） |
| `linear` | 匀速 | 仅调试用 |

### 核心规则

1. **退场/淡出一律 easeOut**（先快后慢），禁止线性淡出——线性淡出有"戛然而止"感
2. 前端转场统一使用 `svelte/easing` 的 `cubicOut`，与 Rust 侧 `ease_out_cubic` 等价
3. 气泡 alpha 最终值 = 动画 alpha × 全局 `opacity`（用户配置 0.4–1.0）
4. 入场期间再次触发事件：直接跳转 `Visible` 态（重置计时），**动画不得阻塞响应**
5. 连击乘数递增（×2→×3）**不重播**入场动画，仅首次出现播放（`MULTIPLIER_BIRTH` 保留首次时间戳）

## 3. 动画架构约束（tiny-skia 渲染路径）

Rust 侧气泡渲染为 CPU 软渲染（tiny-skia + Win32 Layered Window），无 GPU 加速，须遵守：

1. **无 blur filter**：软阴影用多层同心圆角矩形模拟（外扩 2/4/6/8px，alpha 40/25/15/8，见 `SHADOW_LAYERS`），画布四周预留 `SHADOW_PADDING=12px`
2. **渐变**用 `tiny_skia::LinearGradient`，注意 `Paint.shader` 是公有字段（无 setter），`GradientStop::new(f32, Color)` 直接接收非预乘 Color
3. **缩放文字**通过调整字号 + 基线锚点偏移实现（`scaled_y = text_y - (24.0 - font_size) * 0.7`），无逐字形变换
4. **性能预算**：单帧渲染 < 8ms（气泡典型尺寸 < 400×80）；tick 线程 16ms 间隔（60fps）持续投递 `WM_TICK`
5. **重绘触发**：`tick()` 返回 `needs_redraw`；`Visible` 稳态不重绘，乘数动画进行中（<150ms）在 `wndproc` 中强制重绘
6. **像素格式**：pixmap RGBA → DIBSection BGRA 手动转换后 `UpdateLayeredWindow`（`AC_SRC_ALPHA`）

## 4. 色彩 Token（Color Tokens）

### 4.1 气泡样式预设（形状 + 配色，`stylePresets`）

| ID | 形状 | bg | text | border |
|---|---|---|---|---|
| `default` | 圆角矩形 | `#000000` @70% | `#ffffff` | 无 |
| `3d_key` | 3D 按键（底面+渐变顶面） | `#fafafa` | `#212121` | `#e0e0e0` 1px |
| `cartoon` | 卡通（实心投影+高光条） | `#ffffff` | `#111111` | `#000000` 1.5px |
| `retro_terminal` | 直角终端 | `#050505` @95% | `#00ff41` | `#00ff41` 2px |

### 4.2 主题配色预设（仅配色，前后端 ID 一致：`apply_preset` / `stylePresets`）

| ID | bg | bg_opacity | text | border | radius |
|---|---|---|---|---|---|
| `deep_space` | `#101418` | 0.85 | `#e8eaed` | `#2e3a46` 1px | 12 |
| `cream_white` | `#fdf6ec` | 0.95 | `#3d3229` | `#e8d5b7` 1px | 12 |
| `neon_blue` | `#0a1a2f` | 0.9 | `#7df9ff` | `#00d4ff` 1.5px | 10 |

### 4.3 约束

- 主题预设**只替换配色，不改变气泡形状与时间参数**
- 文字与背景对比度 ≥ WCAG AA（4.5:1）
- `CustomStyle` 必须含完整 7 字段（`bg_color/bg_opacity/text_color/border_color/border_width/radius/shadow_color`），缺一即反序列化失败并回退默认
- 乘数文字描边按亮度自适应：`luminance > 0.5` 用黑描边（alpha 150），否则白描边（alpha 200）

## 5. 交互与无障碍

1. 所有可点击卡片提供 `:focus-visible` 焦点环（2px `#007aff`，offset 2px）
2. `prefers-reduced-motion: reduce` 下禁用位移/缩放类 CSS 微交互（保留颜色过渡）
3. 滑块类控件：拖动实时 invoke 后端（100ms 防抖），停顿 700ms 后才持久化写盘
4. 设置持久化键：`osdBubbleSettings`（tauri-plugin-store），后端启动经 `apply_persisted_settings` 防御式恢复

## 6. 变更检查清单

修改任何动画/样式代码时，逐项确认：

- [ ] 时长/缓动数值与本规范一致（不一致则同步更新文档）
- [ ] `cargo test` 全部通过（状态机/缓动/渲染进度均有回归测试）
- [ ] 单帧渲染性能未退化（连击 10 键不掉帧）
- [ ] 入场动画不阻塞连击响应
- [ ] 新增配色满足对比度要求且 `CustomStyle` 字段完整
- [ ] `svelte-check` 零错误、前端动效尊重 reduced-motion
